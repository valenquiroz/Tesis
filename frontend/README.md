# Acompañar · Frontend

Interfaz web de la plataforma de apoyo al cuidador (React + Vite).

```bash
npm install
npm run dev      # http://localhost:5173
npm run lint     # oxlint
npm run build    # genera dist/
```

La URL de la API se configura con `VITE_API_URL` (ver `.env.example`).
Si no se define, se usa `http://localhost:5282/api`.

La documentación completa del proyecto está en `../docs/CLAUDE.md`.
